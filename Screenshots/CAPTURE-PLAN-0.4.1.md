Replace outdated active screenshots rather than appending contradictory old labels.

## File checks before upload

- Preserve the original capture files and their hashes. Keep any upload derivatives separate.
- Use JPG or PNG, each **under 1,000,000 bytes**, matching the existing Workshop preparation limit.
- Gameplay images can retain their native aspect ratio. Only `About/Preview.png` must keep the project's **16:9** cover shape and stay below the same byte limit.
- Check text readability at the intended display size, no clipped controls, current labels and a representative configuration.
- Record dimensions, byte sizes, order, captions, filenames and SHA-256 in the new gallery manifest before replacing links or uploading.

The candidate UI should be checked in-game first. Copy changes do not require image editing, and these planned captures are not marked complete until supplied and inspected.
